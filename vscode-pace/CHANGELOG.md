# Changelog

All notable changes to the Pace VS Code extension are documented here.

## 0.4.0

- Added schema-generated language metadata, snippets, grammar keywords, and language reference.
- Added CLI-backed diagnostics with `pace validate --json`.
- Added task commands, CodeLens task actions, document symbols, hover documentation, and reference completions.
- Added packaging, CI, local install scripts, and generated artifact freshness checks.

Release updates should add a new entry before publishing a VSIX or marketplace release.
