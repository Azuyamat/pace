# Pace Language Support for VS Code

Syntax highlighting and autocomplete support for Pace configuration files (`.pace`).

## Features

- **Syntax Highlighting**: Full syntax highlighting for Pace configuration files
- **Comment Support**: Line comments with `#`
- **Auto-closing**: Automatic closing of brackets, braces, and quotes
- **Code Folding**: Fold task, hook, and block definitions
- **Variable Highlighting**: Highlights variable interpolation (`${VAR}` and `$VAR`)
- **Autocomplete**: Provides snippets for top-level statements, task properties, hook properties, `args` block properties, and task/hook references
- **Outline**: Shows Pace tasks and hooks in the VS Code Outline panel
- **CodeLens**: Adds `Run task` actions above task definitions; tasks with `watch true` also show `Watch task`
- **Hover Documentation**: Shows documentation for supported statements and properties
- **Diagnostics**: Runs `pace validate --json` to surface parser and validation errors in Problems
- **Commands**: Generate `config.pace`, run the current/selected task, run the default task, and insert Go task templates generated by the Pace CLI

## Supported Syntax

The supported language metadata is generated from the Go-owned schema. See [LANGUAGE_REFERENCE.generated.md](./LANGUAGE_REFERENCE.generated.md) for the generated reference, and see [examples/](./examples/) for complete files used in manual testing.

- **Keywords**: `var`, `default`, `alias`, `import`, `hook`, `task`
- **Task Properties**: `command`, `inputs`, `outputs`, `depends-on`, `dependencies`, `env`, `cache`, `working_dir`, `requires`, `before`, `triggers`, `after`, `description`, `watch`, `parallel`, `silent`, `continue_on_error`, `timeout`, `retry`, `retry_delay`, `on_success`, `on_failure`, `when`, `args`
- **Hook Properties**: `description`, `command`, `env`, `working_dir`
- **Args Properties**: `required`, `optional`
- **Strings**: Single-line (`"..."`) and multi-line (`"""..."""`)
- **Variables**: Variable interpolation in strings (`${VAR}` or `$VAR`)
- **Comments**: Line comments with `#`
- **Booleans**: `true`, `false`
- **Numbers**: Including duration suffixes (`5m`, `30s`, etc.)
- **Arrays**: Support both comma-separated values with identifiers or strings, such as `[build, "test"]`
- **Maps/blocks**: Environment maps use assignment syntax, such as `env { KEY = "value" }`

Task dependency aliases are both supported: `depends-on` and `dependencies`. Hook relationship aliases are both supported: `requires`/`before` for hooks that run before a task, and `triggers`/`after` for hooks that run after a task. Standalone `alias short task_name` remains supported, but inline task aliases (`task build [b] { ... }`) are preferred.

## Installation

### Option 1: Install from VSIX (Recommended)

1. Install dependencies and package the extension:
   ```bash
   cd vscode-pace
   npm ci
   npm run package
   ```

2. Install in VS Code:
   - Press `Ctrl+Shift+P` (Windows/Linux) or `Cmd+Shift+P` (Mac)
   - Type "Extensions: Install from VSIX"
   - Select the generated `.vsix` file

   Or install from a shell with `npm run install:local`. The install script uses the VS Code `code` command and shell glob expansion; on shells that do not expand `*.vsix`, use the Command Palette flow above.

### Option 2: Development Mode

1. Install dependencies:
   ```bash
   cd vscode-pace
   npm ci
   ```
2. Run `npm run dev` to compile and launch an Extension Development Host, or press `F5` from VS Code.
3. Open any `.pace` file to see syntax highlighting and completions.

## Usage

Simply open any file with a `.pace` extension, and syntax highlighting plus Pace completions will be automatically applied.

Available commands:

- `Pace: Generate config.pace`: runs the Pace CLI initializer in the selected workspace folder and asks before overwriting an existing file.
- `Pace: Run Current Task`: runs the task under the cursor, or prompts for a task if the cursor is outside a task block.
- `Pace: Run Task`: lists tasks from the current document and runs the selected task.
- `Pace: Run Default Task`: runs `pace run` in the workspace folder.
- `Pace: Insert Generated Go Task`: asks the Pace CLI for Go project task suggestions and inserts the selected task definition.
- `Pace: Show Schema Version`: shows the bundled language schema version and, when available, the installed Pace CLI schema version.

## Development

Useful scripts:

- See [CONTRIBUTING.md](./CONTRIBUTING.md) for setup, generated-file, packaging, and release development notes.
- `npm run generate:schema`: regenerate bundled schema, snippets, grammar keyword data, and language reference from the Go schema.
- `npm run compile`: compile TypeScript into `build/`.
- `npm run watch`: compile continuously while developing.
- `npm test`: run unit tests for scanners, symbol extraction, and completions.
- `npm run package`: compile and create a VSIX using the local `@vscode/vsce` dev dependency.
- `npm run install:local`: install the generated VSIX with the VS Code CLI.
- `npm run dev`: compile and launch VS Code with this extension as the development extension.

Root workspace tasks under **Pace VS Code:** run the same compile, watch, test, package, and local install actions from VS Code's task runner.

Language schema, snippets, grammar keyword data, bundled JSON schema, and the generated language reference are generated from Go:

```bash
npm run generate:schema
```

CI runs this command and fails if generated artifacts are not committed.

`build/` is intentionally not committed. Packaging and CI compile from `src/` in a clean checkout before creating the VSIX.

## Settings

- `pace.path` (default: `pace`): path to the Pace CLI executable used by diagnostics and task commands.
- `pace.diagnostics.enabled` (default: `true`): enable or disable CLI-backed diagnostics.
- `pace.diagnostics.run` (default: `onType`): run diagnostics after edits (`onType`) or only on save (`onSave`).
- `pace.codeLens.enabled` (default: `true`): enable or disable CodeLens actions above task definitions.
- `pace.completions.projectAware` (default: `false`): enables project-aware features as they become available. Go task template insertion is sourced from the Pace CLI to avoid duplicating Go project detection in TypeScript.
- `pace.logging.debug` (default: `false`): write verbose extension logs to the `Pace` output channel.
- `pace.schema.versionWarnings.enabled` (default: `true`): warn when the installed Pace CLI language schema version is incompatible with the bundled extension schema.

Hooks do not currently show CodeLens actions because hooks are referenced by tasks and are not exposed as directly runnable Pace commands.

The extension contributes a `$pace` problem matcher for tasks that emit diagnostics in `file:line:column: severity: message` format.

## Compatibility and privacy

The extension bundles a schema generated from the Go source so it works without the Pace CLI installed. When the CLI is available, the extension can compare schema versions and report major compatibility mismatches; disable this with `pace.schema.versionWarnings.enabled` if needed.

No telemetry is collected by this extension.

The extension contributes a marketplace icon but intentionally does not contribute a file icon theme; `.pace` files and `config.pace` are associated with the Pace language.

## Example

```pace
# Define variables
var BUILD_OUTPUT = "pace.exe"
var VERSION = "1.0.0"

# Set default task
default build

# Define a task with inline alias
task build [b] {
    description "Build the Pace executable"
    command "go build -ldflags '-X main.Version=${VERSION}' -o ${BUILD_OUTPUT} cmd/pace/main.go"
    inputs [cmd/**/*.go, internal/**/*.go]
    outputs [${BUILD_OUTPUT}]
    cache true
    timeout "5m"
    env {
        GOOS = "linux"
    }
}

# Define a hook
hook test {
    description "Run tests"
    command "go test ./..."
}

# Task with dependencies
task release [r] {
    description "Build release version"
    requires [test]
    depends-on [build]
    command "echo 'Release ready'"
}
```
